# Student Management System

A simple and user-friendly Student Management System designed to manage student information efficiently.

## 📌 About the Project

The Student Management System is a software application that helps manage student records, academic information, and other student-related data in one place.

## ✨ Features

- Add New Students
- View Student Information
- Update Student Records
- Delete Student Records
- User-Friendly Interface
- Easy Student Data Management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
